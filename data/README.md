# RazorGuard Dataset

## Purpose

This directory contains datasets used for developing and evaluating RazorGuard.

## Raw Data

Raw datasets are stored in `data/raw/`.

Raw datasets are not modified after download.

## Processed Data

Processed datasets generated by RazorGuard are stored in `data/processed/`.

## Dataset Sources

The initial fraud-detection dataset is a publicly available credit-card transaction dataset containing anonymized transaction features and fraud labels.

## Synthetic Data

RazorGuard may generate synthetic merchant-level and behavioral attributes where the public dataset does not provide the required information.

Synthetic attributes will be clearly documented and will not be represented as real Razorpay transaction data.

## Privacy

RazorGuard does not use real customer personally identifiable information.

## Reproducibility

Dataset preprocessing and synthetic-data generation steps will be documented in the project.
